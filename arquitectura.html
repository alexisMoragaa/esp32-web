03 / ARQUITECTURA

Una web
en una placa.

+

Esta web está siendo servida directamente desde una ESP32-S3. No es una maqueta que luego llegará al hardware: la placa es el servidor que entrega cada página que estás leyendo.

El desarrollo está optimizado para sus límites: archivos estáticos, JavaScript mínimo, recursos comprimidos y sin backend de por medio. El código se prepara localmente; la ESP32 hace el resto.

CLOUDFLARE TUNNEL / CONEXIÓN

El túnel abre la puerta.
La placa sirve la web.

La conexión externa atraviesa un canal seguro hasta la red local. El túnel solo transporta la solicitud: la respuesta, el HTML y los recursos salen directamente desde la ESP32-S3.

03 / decisiones

01

La placa sirve el sitio

La ESP32-S3 es el servidor web principal. Las páginas y recursos se entregan directamente desde su memoria.

02

El túnel solo conecta

La capa de acceso reenvía las solicitudes hacia la ESP32 dentro de la red local, sin alojar el contenido.

03

El desarrollo ocurre aquí

El código, el contenido, el build de producción y la preparación de los archivos se realizan en el equipo local.
