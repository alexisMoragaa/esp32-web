03 / ARQUITECTURA

Una web
en una placa.

+

Esta web está siendo servida directamente desde una ESP32-S3. No es una maqueta que luego llegará al hardware: la placa es el servidor que entrega cada página que estás leyendo.

El desarrollo está optimizado para sus límites: archivos estáticos, JavaScript mínimo, recursos comprimidos y sin backend de por medio. El código se prepara localmente; la ESP32 hace el resto.

02 / decisiones

01

La placa sirve el sitio

La ESP32-S3 es el servidor web principal. No depende de un backend ni de un proceso de compilación en el Mini PC.

02

El Mini PC solo conecta

Su única responsabilidad será ejecutar Cloudflare Tunnel y reenviar las solicitudes hacia la ESP32 dentro de la red local.

03

El desarrollo ocurre aquí

El código, el contenido, el build de producción y la preparación de los archivos se realizan en el equipo local.
